Understanding JSON Structure

From what I observed, the JSON file contains information about the book Fantastic Mr. Fox. The information is organized into different name/value pairs, objects, arrays, and nested structures.

Name/Value Pair

A name/value pair basically connects a key to its value. An example would be the title of the book. 

"title": "Fantastic Mr. Fox"

Object

An object uses curly brackets to organize different pieces of information together. 

"first_sentence": {
    "type": "/type/text",
    "value": "Down in the valley there were three farms."
}

Array

An array is a collection of values stored together using square brackets. 

"covers": [15152634, 8739161, -1]

Nested Structure

A nested structure is when an object or array contains additional information within it. An example would be the authors array, which contains an object. 

"authors": [
    {
        "key": "/authors/OL34184A"
    }
]
